EARS ORGAN
==========

Purpose
-------
The ears organ listens to the microphone, collects the incoming audio, and converts spoken English into text. When the speaker pauses, the recognized text is sent to the Brain organ for processing.

How it works
------------
1. The module loads SoundDevice for microphone input, NumPy for audio processing, a queue for thread-safe communication, and Faster Whisper for speech recognition.
2. It loads the small Whisper model on the CUDA device. The small model is chosen to provide faster transcription.
3. Audio is recorded as mono audio at 16,000 samples per second.
4. The microphone is divided into blocks of 0.5 seconds. Each block is copied into an audio queue by the audio callback.
5. The recorder runs continuously in a background daemon thread. It keeps the microphone stream open and places captured blocks into the queue.
6. The transcriber removes blocks from the queue and stores them in an audio buffer.
7. Once the buffer contains approximately five seconds of audio, the blocks are combined, flattened, and converted to float32 audio data.
8. Faster Whisper transcribes the audio in English using a beam size of 1. Each recognized segment is printed and added to the speech text list.
9. When a five-second chunk produces no transcription, the module treats this as the end of the spoken prompt. It joins all collected text and sends it to Brain.think().
10. After the prompt is sent, the collected speech text is cleared and the current transcription cycle ends.

Important functions
-------------------
audio_callback(): Receives microphone data and places a copy in the shared audio queue. It also reports stream status messages.

recorder(): Opens the SoundDevice input stream and keeps recording. It runs in the background so audio capture can continue while another function processes the queue.

transcriber(): Builds five-second audio chunks, sends them to Whisper, collects the recognized text, detects a pause, and passes the completed prompt to the Brain organ.

hear(): The public entry point. It starts the recorder thread and then begins transcription.

Shared data
-----------
audio_queue transfers microphone blocks from the recorder callback to the transcriber.
audio_buffer temporarily stores blocks until there are enough frames for a transcription.
speech_texts stores recognized segments belonging to the current spoken prompt.

Dependencies and requirements
-----------------------------
The computer needs a working microphone, SoundDevice, Faster Whisper, NumPy, and a CUDA-capable setup compatible with the selected Whisper model. The module imports Brain so that completed speech can move to the thinking stage.

Current limitation
------------------
The transcription loop ends after one detected pause. Calling hear() again is required to listen for another prompt.
